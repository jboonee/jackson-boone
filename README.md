### 2. Real-Time Audio Communication Program

**Technologies Used:**  
Networking Concepts, Audio Processing, Client-Server Communication

**Description:**  
This project involved creating a program capable of detecting audio from a microphone and transmitting it live to another computer running the same application. The program establishes a network connection between two machines and streams audio data in real time so both users can communicate. In addition to live audio communication, the application also includes a built-in text chat feature that allows users to send messages while the audio stream is active. This project demonstrates knowledge of networking, real-time data transmission, and interactive communication systems.

### 3. CalorieMate – Calorie Tracking Web Application

**Technologies Used:**  
Python, Flask, MySQL, SQLAlchemy

**Description:**

The application includes a basic user model and database structure that can be expanded to support food tracking, exercise logging, and user authentication. This project demonstrates experience with backend web development, database integration, and building scalable application foundations using Python.
